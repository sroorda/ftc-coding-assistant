# Mentor Hub

> **Audience: adult mentors and course maintainers.** Student lessons begin at
> [Set Up Your Computer](GETTING_STARTED.md).

This section contains facilitation, assessment, safety, curriculum-planning, and
publishing guidance. Keep those responsibilities with adults so the student course
can speak directly to learners.

## Teach Level 1

- Read the [Adult Mentor Guide](mentors/adult-mentor-guide.md) for the help ladder,
  responsible AI use, and supervision boundaries.
- Use the [Level 1 Instructor Guide](instructor/instructor-guide.md) for preparation,
  lesson notes, expected results, and assessment.
- Run every lesson before the students arrive. Remember that Lesson 5 begins with
  an intentional failing test.

## Prepare later levels

- Review the [program design notes](mentors/program-design.md) before turning a
  planned level into student lessons.
- Evolve the team's base framework using
  [Robot Code Architecture](docs/robot-code-architecture.md).
- Verify the current FTC SDK, hardware, Pedro Pathing version, safety procedure,
  and Windows development process with the team's actual equipment.

## Maintain and publish

GitHub is the source of truth and GitBook is the student reading experience. Follow
[Contributing and Publishing](CONTRIBUTING.md) for validation and synchronization.

AI may assist with preparation and review, but it is not an accountable mentor.
Adults remain responsible for students, hardware safety, privacy, repository
permissions, and final technical decisions.
